## Uso de la API de la Bolsa de Santiago

1. Obtén tu token gratuito desde la Bolsa de Santiago.
2. Exporta el token como variable de entorno:
   ```bash
   export BOLSASANTIAGO_TOKEN="TU_TOKEN"
   ```
3. Ejecuta el script básico para consultar acciones:
   ```bash
   python bolsa_santiago.py
   ```
   El script mostrará la respuesta cruda de la API o un mensaje de error si la solicitud falla.
